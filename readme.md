# Booksspine – Mobile Book Store App

**Booksspine** is a mobile application designed to sell **original books** and **print-on-demand books**, with plans to introduce **eBooks** in a future version.

This project focuses on providing a smooth, secure, and reliable book-buying experience for readers.

---

##  Project Vision

Booksspine aims to build a trusted digital bookstore where users can:
- Buy **100% original printed books**
- Order **print-on-demand books**
- Access books easily via a mobile app
- Enjoy a modern and user-friendly shopping experience

**eBooks will be introduced in Version 2.**

---

## Features

### Version 1 (Current)
-  Browse books by categories
-  Search books
-  Add to cart & checkout
-  Print-on-demand ordering
-  Order tracking
-  User authentication (Login / Signup)
-  Wishlist / favorites

### Version 2 (Planned)
-  eBook marketplace
-  Buy & download eBooks
-  In-app eBook reader
-  Secure digital content access

---

##  Tech Stack (Planned)

- **Mobile App:** React Native / Flutter
- **Backend:** Node.js (API based)
- **Database:** MongoDB / Firebase
- **Authentication:** JWT / Firebase Auth
- **Payments:** Stripe / Local gateways
